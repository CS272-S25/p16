# EcoGoods 

EcoGoods is a straightforward online store where customers can browse and purchase eco-friendly goods. It demonstrates how HTML, CSS, and JavaScript work together to produce a functional, interactive website.

# Features
- 4 pages: Home, Shop, Cart, About
- Navbar with links on every page
- Uses Bootstrap for responsive design
- Global and page-specific CSS files
- JavaScript to update pages and handle cart items
- Uses localStorage to save cart data
- Form to simulate checkout
- Fetches product info from an external API
- Includes a semantic tag <details> not covered in class
